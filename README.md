## Описание
- веб-приложение "Чат", мессенджер для обмена сообщениями
- в данной версии отрисованы макеты основных экранов: Login, Registration, Chat, Setting
- переход по страницам осуществляется через навигационную панель
- реализована валидация форм: Login, Registration, Setting ()
- подключена работа с HTTP API чатов: регистрация, авторизация и выход из ситемы, изменение данных пользовалтеля, создание и удаление чатов, добавление пользователей в чат и обмен сообщениями
- ! для обмена сообщениями в реальном времени необходимо подключение двух участников чата
